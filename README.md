### Итоговая таблица
|Конструкция|Когда использовать|
| -------- | ----------------------- |
|if/else |Общее ветвление, сложные условия|
|else if|Несколько взаимоисключающих вариантов|
|switch/case|Сравнение одной переменной с конкретными

### Ответы на вопросы
1. Чем int.TryParse() безопаснее int.Parse()? В каких случаях стоит использовать
каждый?
**Ответ:** int.Parse(), когда точно число, а int.TryParse(), когда ввод. потому что int.TryParse() возвращает true/false, а int.Parse() ошибку, если это не число
2. Когда switch удобнее, чем цепочка if/else if? Приведите пример из реальной
жизни.
**Ответ:** Когда много вариантов. Пример: программа, которая определяет время года по номеру месяца
3. Что произойдёт в switch, если убрать break после одного из case?
**Ответ:** Выполнится код и этого и следующего case
4. Чем отличается = от == в C#? Почему это частая ошибка?
**Ответ:** = это присваивание, а == это сравнение. Не знаю, почему это частая ошибка, почти во всех языках же так
5. Можно ли написать тернарный оператор внутри другого тернарного
оператора? Приведите пример из кода лабораторной и оцените читаемость
такого кода.
**Ответ:** Можно, читается нормально, если понимать как работает тернарный оператор
